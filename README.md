# Training Center Management System

A C# console application designed to manage training center courses and students using Object-Oriented Programming (OOP) principles.

## Features
- Student Management: Register students and manage their information.
- Course Management: Add courses and assign them to students.
- OOP Architecture: Clean and structured codebase built using C# classes and methods.

## Technologies & Concepts Used
- Language: C#
- Concepts: Object-Oriented Programming (OOP), Classes & Objects
- IDE: Visual Studio

## How to Run
1. Clone the repository or download the source code.
2. Open Training Center Management System.slnx in Visual Studio.
3. Press F5 or Ctrl + F5 to build and run the application.
